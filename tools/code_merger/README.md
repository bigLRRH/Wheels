# code_merger

`code_merger.py` 是一个用于将指定文件夹下所有源代码文件（如 `.py`, `.js`, `.rs` 等）按格式合并到一个文件中的实用脚本。它会在合并的代码段之间添加源文件的路径作为注释标题，方便阅读和追踪来源。

## 特性

- 递归遍历整个目录结构
- 支持多种常见的代码文件类型
- 自动在每段代码前添加文件路径作为标题
- 忽略无法读取的文件并打印警告

## 使用方法

### 1. 修改脚本中的路径

在脚本顶部设置以下变量为你本地的实际路径：

```python
source_folder = "/path/to/your/code_folder"
output_file = "/path/to/output/merged_code.txt"
```

你也可以添加或修改支持的文件扩展名列表：
    
```python
extensions = [".py", ".js", ".ts", ".rs", ".cpp", ".c", ".h", ".html", ".css", ".vue"]
```

### 2. 运行脚本

```python
python code_merger.py
```

## 查看输出
合并后的代码将保存在 `output_file` 指定的路径下。你可以使用任何文本编辑器打开它进行查看和编辑。

## 注意事项
输出文件会被覆盖，请确保提前备份。

确保目录中所有文件的编码为 UTF-8，否则可能出现读取错误。

文件较多或较大时运行可能需要一些时间。
